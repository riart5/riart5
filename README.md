## Proyectos destacados

### [gestor-turnos](https://github.com/riart5/gestor-turnos)

Aplicación web para gestionar los turnos del personal de enfermería: cambios de turno con doble aprobación, solicitudes de ausencia, avisos de cobertura y vista de calendario pensada para el móvil. API en Node.js y Express con Prisma y MariaDB, y frontend en React. Diseñada desde el principio para dar servicio a varios hospitales con la misma instalación.

### [gymphysical_MVC](https://github.com/riart5/gymphysical_MVC)

Aplicación en PHP con arquitectura MVC y un único punto de entrada, para practicar la separación entre modelos, vistas y controladores.
